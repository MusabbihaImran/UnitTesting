# Python Unit Testing

A small Python project demonstrating fundamental unit testing concepts using Python's built-in `unittest` framework.

The project was developed as part of university coursework to practice writing and organizing automated tests.

## 📂 Project Structure

```text
UnitTesting/
├── Calculator.py       # Calculator functionality
├── TestCalculator.py   # Unit tests for the calculator
├── MockExamples.py     # Examples demonstrating mocking
├── README.md
└── LICENSE
```

## 🧪 What This Project Demonstrates

* Writing unit tests with Python's `unittest`
* Testing individual functions and behaviors
* Organizing test cases
* Using assertions to verify expected results
* Basic mocking concepts
* Separating application code from test code

## 🛠️ Technologies

* Python
* `unittest`
* Mocking

## ▶️ Running the Tests

Make sure Python is installed, then run:

```bash
python -m unittest TestCalculator.py
```

Alternatively, you can run:

```bash
python -m unittest discover
```
